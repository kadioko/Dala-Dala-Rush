# Optional Gameplay Sprites

Place optional PNG overrides in this folder. The game keeps its procedural
vector art whenever a matching file is absent.

Use these naming patterns:

- `vehicle_<vehicle_id>.png`
- `obstacle_<type_id>.png`
- `collectible_<type_id>.png`

See `docs/SPRITES.md` for the complete filename list, dimensions, style, and
import QA requirements.
